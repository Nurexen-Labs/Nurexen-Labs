# Nurexen Labs

Building assurance infrastructure for programmable commerce.

## SafeGate

**Payment proves value moved. SafeGate proves what happened next - and makes the strength of that proof explicit.**

SafeGate is a rail-agnostic, chain-agnostic commerce verification and evidence layer for:

- AI agents
- paid APIs
- MCP tools
- digital services
- merchants
- platforms
- Web3 commerce

SafeGate does not replace payment rails.

It provides an independent assurance layer around what happens after payment.

## Current SafeGate Stack

- Public Verify API
- Observed Middleware Core
- MCP / Agent Tool
- Public JavaScript SDK
- Developer Quickstart
- Base Mainnet USDC verification adapter
- Portable CommerceProof semantics

## Assurance Model

**CLAIMED**  
Provider-attested outcome evidence.

**OBSERVED**  
SafeGate observed execution or response evidence.

**VALIDATED**  
An independent validation mechanism verified the outcome.

**THIRD_PARTY_ATTESTED**  
An external party contributed evidence under its own trust mechanism.

**Payment verification alone does not prove fulfillment.**
